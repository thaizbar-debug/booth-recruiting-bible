## How to Use This Folder

1. **Start with general-questions.md** — answer every question there first
2. **Pick your target track** — read the track-specific file
3. **Map your stories** — use the story → question table in each file
4. **Practice out loud** — record yourself, book a Booth Career Services mock interview
5. **Update after every real interview** — what was asked that wasn't here?
